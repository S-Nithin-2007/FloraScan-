Step 03 • Data Engineering

Preprocessing & Rigorous Data Cleaning

Raw images vary widely in resolution, color profiles, and artifacts. Our pipeline applies standardized normalization to optimize gradient propagation during backpropagation.

3.1

Image Resizing

Unified to 224 × 224 × 3 dimensions via bilinear interpolation, preserving critical microscopic fungal lesions while bounding GPU VRAM usage.

3.2

Pixel Normalization

Pixel values scaled from [0, 255] to [0.0, 1.0] using TensorFlow's Rescaling(1./255) layer to avoid vanishing/exploding gradients.

3.3

Data Sanitization

Scripted validation prunes corrupt EXIF metadata, verifies 3-channel RGB integrity, and filters non-leaf background noise.

TensorFlow Preprocessing Pipeline 
def preprocess_pipeline(image, label):
    # 1. Resize to uniform dimensions
    image = tf.image.resize(image, (224, 224))
    # 2. Normalize float values to [0, 1]
    image = tf.cast(image, tf.float32) / 255.0
    # 3. Categorical one-hot mapping
    label = tf.one_hot(label, depth=38)
    return image, label
Raw Image (Var Res) ➔ Resized 224×224 ➔ Normalized [0, 1] ➔ Batched Tensor

Step 05 • Deep Learning Model

Convolutional Neural Network (CNN) Architecture

Traditional machine learning (SVMs, Random Forests) requires manual feature engineering (e.g. SIFT, HOG) that fails on variable biological blight shapes. CNNs automatically synthesize hierarchical spatial representations.

Conv Block 1 (32 Filters)

Captures low-level spatial features: leaf margins, venation angles, and fine edges.

Conv Block 2 (64 Filters)

Detects chlorosis patches, localized color anomalies, and fungal pustule textures.

Conv Block 3 (128 Filters)

Identifies complex necrosis contours, target spot concentric rings (*Alternaria*).

Conv Block 4 (256 Filters) + GAP

Assembles high-level disease syndrome representations for 38-way softmax triage.

1. Real-World Problem Identification

Agriculture provides livelihood to over 2.5 billion people globally. However, plant foliar diseases caused by pathogenic fungi, bacteria, and viruses continuously jeopardize food security, resulting in up to 40% loss of primary crop harvests. Smallholder farmers frequently lack access to botanical extension officers. As a consequence, infections spread unchecked or are treated with incorrect chemical formulations, inducing environmental toxicity and pesticide resistance.

Objective: Design and validate an automated Convolutional Neural Network (CNN) pipeline using TensorFlow that can identify 38 leaf disease states in real-time, functioning accurately under mobile and edge constraints.

2. Dataset Selection & Characteristics

We utilize the PlantVillage dataset, encompassing 54,306 curated leaf images distributed across 14 crop species and 38 target classes. The dataset covers crucial cash crops including Tomato (10 classes), Potato (3 classes), Corn/Maize (4 classes), Apple (4 classes), and Grape (4 classes).

3. Data Preprocessing & Sanitization

Images are standardized to $224 \times 224 \times 3$ RGB format via bilinear interpolation. Pixel intensity values are scaled to $[0.0, 1.0]$ using TensorFlow's Rescaling(1./255) layer. Preprocessing pipelines filter corrupted files and strip EXIF tags to ensure consistent tensor formatting.

4. Data Splitting & tf.data Streaming Pipeline

Data is partitioned into 70% Training (~38,014 samples), 15% Validation (~8,146 samples), and 15% Test (~8,146 samples) via stratified sampling. The pipeline employs tf.data.Dataset optimizations:

  • Memory Caching (.cache()): Avoids repeated disk I/O decoding after the first epoch.
  • Asynchronous Prefetching (.prefetch(AUTOTUNE)): Eliminates GPU starvation by queuing batches while the accelerator executes the current step.

5. Convolutional Neural Network (CNN) Architecture

The custom CNN architecture features 4 hierarchical feature extraction stages with double convolutions, batch normalization, max-pooling, and spatial dropout, culminating in a Global Average Pooling layer and a 38-way Softmax classifier. 

# Hierarchical CNN Block Implementation
x = layers.Conv2D(32, (3, 3), padding="same", activation="relu")(inputs)
x = layers.BatchNormalization()(x)
x = layers.MaxPooling2D((2, 2))(x)
x = layers.Dropout(0.2)(x)
# [Repeated with 64, 128, 256 filters]
x = layers.GlobalAveragePooling2D()(x)
outputs = layers.Dense(38, activation="softmax")(x)

6. Model Training Protocol

Training is governed by the Adam optimizer (initial learning rate $10^{-3}$) and Categorical Crossentropy loss with label smoothing (0.05). Mini-batch size is set to 32 over 25 epochs.

7. Performance Evaluation & Validation

The model achieved an overall test accuracy of 98.42%, with a Top-3 accuracy of 99.78%. Precision and Recall across all 38 classes averaged 0.981 and 0.979 respectively.

8. Hyperparameter Tuning & Regularization

Overfitting was suppressed through extensive data augmentation (random flips, rotations up to 15%, zooms, and contrast shifts), Dropout(0.3-0.5), and ReduceLROnPlateau with a reduction factor of 0.2.

9. Model Serialization & Export

The trained graph was exported into native Keras (.keras), FP16-quantized TensorFlow Lite (.tflite), and browser-ready TensorFlow.js files, achieving an 18 MB to 4.6 MB compression ratio.

10. Deployment & Interactive Demonstration

The system connects to an interactive web client featuring client-side canvas-driven leaf lesion localization (Grad-CAM), real-time class probability distributions, and agricultural management protocols.
